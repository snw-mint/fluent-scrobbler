# Security Policy

> [!CAUTION]
> Always download Fluent Scrobbler exclusively from this page or our official GitHub Releases repository. We take no responsibility for packages obtained from third-party websites.

## Supported Versions

Since this project is currently in early development (Beta), only the latest release receives security updates and patches.

## Reporting a Vulnerability

We take the security of this application seriously. If you believe you have found a security vulnerability in this project, please do **NOT** open a public GitHub issue.

### How to Report

Please report security vulnerabilities through one of the following methods:

1. **GitHub Private Vulnerability Reporting (Preferred):** Go to the **Security** tab of this repository, click **Report a vulnerability**, and submit your findings.
2. **Email:** Send a detailed description to `snowmint.dev@gmail.com` _(replace with your real contact email)_.

### What to Include in Your Report

To help us understand and resolve the issue quickly, please include:

- A description of the vulnerability and its potential impact.
- Step-by-step instructions (or a Proof of Concept script/steps) to reproduce the issue.
- Details about your environment (e.g., Windows 10/11 version, system architecture).

### What to Expect

- **Acknowledgment:** We will aim to acknowledge your report within **48 hours**.
- **Assessment:** We will investigate the issue and determine the appropriate fix.
- **Resolution:** Once a fix is ready, we will release a patch release and notify you before making the advisory public.

Thank you for helping keep this project and its users safe! :)
